# Κώδικας ανάλυσης διπλωματικής

Το πακέτο περιέχει τα τρία πλήρη scripts, χωρίς απαντήσεις, χρονοσημάνσεις ή παράγωγα ανά συμμετέχοντα. Για αναπαραγωγή απαιτείται χωριστή, εξουσιοδοτημένη πρόσβαση στο αρχείο Raw_100_Locked.xlsx. Ο έλεγχος SHA-256 πρέπει να παραμείνει ενεργός.

Με Python 3.12, σε ξεχωριστό περιβάλλον:
1. python -m pip install -r requirements.txt
2. Τοποθετήστε το Raw_100_Locked.xlsx δίπλα στα scripts.
3. python analyse_survey.py --input Raw_100_Locked.xlsx
4. python verify_analysis.py
5. python extended_analysis.py --input Raw_100_Locked.xlsx

Τα scripts δημιουργούν τοπικά αρχεία που μπορεί να περιέχουν εγγραφές ανά συμμετέχοντα. Μην ανεβάζετε τους φακέλους results και figures ούτε τα αρχεία δεδομένων στο δημόσιο αποθετήριο. Η τοπική επανεκτέλεση δεν αποτελεί ανεξάρτητη αναπαραγωγή της μελέτης.
